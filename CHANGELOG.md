# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-03

### Added
- Pomodoro timer with Focus, Short Break, and Long Break modes
- Customizable timer durations and auto-start functionality
- Progress ring visualization for active timers
- Integrated task management with reordering, prioritization, and tags
- Comprehensive statistics dashboard (daily/weekly charts, focus streaks, heatmaps)
- Fullscreen immersive Focus Mode
- Distraction tracking and mood/focus quality logging
- Ambient background sounds (Rain, Cafe, White Noise)
- fully offline-capable Progressive Web App (PWA) architecture
- Data export functionality (CSV)
- Zero-dependency local storage data persistence
- Accessibility improvements (ARIA labels, keyboard navigation)
